# 数据预处理效果可视化与合理性审计

> 数据范围：30 名受试者、752 个 30 秒窗口。
> 图形格式：PNG（320 dpi）与可编辑矢量 PDF。
> 目的：验证预处理是否在时域、频域、事件标签、压力空间结构和全数据质量层面具有技术合理性。

---

## 1. 评价原则

预处理效果不能只靠一个“看起来干净”的窗口证明。本报告采用五层证据：

1. **时域审计**：同时展示队列代表性窗口和高伪影窗口；
2. **频域审计**：使用全部 752 个窗口统计滤波前后的功率谱；
3. **事件审计**：检查 ECG R 峰、PPG 脉搏峰及两路心率一致性；
4. **空间审计**：检查 1056 路采集向量经硬件接线映射为 77×32 后，插值、前景提取及体位空间结构是否合理；
5. **质量审计**：展示全部窗口在不同体位下的异常尾部和质量门通过率。

这里的“合理性”是指：

- 实现符合预先设定的频带；
- 没有明显滤波发散或数值异常；
- 主要生理事件在处理后仍可辨识；
- 质量差异没有被预处理掩盖；
- 压力重排产生可重复的空间结构。

这些图不能单独证明临床有效性，也不能证明 BCG 心搏成分足以恢复 ECG。

## 2. 时域效果

![时域预处理审计](experiments/preprocessing_visualization/figure1_time_domain_audit.png)

### 2.1 样本选择方式

图中没有人工挑选“最好看的”窗口：

- 左列是多维质量指标空间中的队列中心样本，即质量 medoid：
  - 匿名受试者 S002；
  - 第 15 个窗口；
  - Right Side。
- 右列是预先定义伪影负担分数约第 95 百分位的窗口：
  - 匿名受试者 S016；
  - 第 16 个窗口；
  - Left Side。

伪影分数综合考虑：

- ECG 轨到轨饱和；
- RR 不规则性；
- PPG 两路一致性；
- PPG 心率分歧；
- BCG 尖峰；
- 压力帧间变化。

### 2.2 可以观察到的效果

代表性窗口中：

- 线性去趋势去除了胸廓压力的慢漂移，但没有把呼吸波动抹平；
- `0.08–0.70 Hz` 分量形成连续的低频呼吸候选波形；
- `0.8–8 Hz` 和高频包络保留了较快的机械变化；
- ECG 经 `0.5–40 Hz` 滤波后 R 峰仍清晰；
- PPG 经 `0.4–8 Hz` 滤波后脉搏周期更加突出。

高伪影窗口中：

- BCG 仍存在大幅慢变化和短时尖峰；
- ECG 出现明显基线和幅度异常；
- PPG 局部脉搏形态发生畸变。

这说明预处理没有把异常窗口“美化”为正常信号，后续质量模型仍能观察到伪影。这一点对质量感知和拒识研究很重要。

### 2.3 结论

时域结果支持：

- 稳健标准化没有造成整体波形崩溃；
- 目标频带在常规窗口中具有清晰结构；
- 极端伪影仍然可见，因此必须保留质量门控。

但仅凭时域图不能断言 `0.8–8 Hz` 分量一定是真实心搏。

## 3. 频域效果

![频域预处理审计](experiments/preprocessing_visualization/figure2_frequency_domain_audit.png)

### 3.1 统计方式

频域曲线使用全部 752 个窗口：

- 实线为窗口归一化 PSD 的中位数；
- 阴影为四分位区间；
- 横轴采用对数频率；
- 背景色表示预先定义的目标频带。

### 3.2 目标频带能量集中度

| 信号/分量             | 原始中位频带占比 | 处理后中位频带占比 |
| --------------------- | ---------------: | -----------------: |
| 呼吸`0.08–0.70 Hz` |            0.878 |              0.991 |
| 心搏候选`0.8–8 Hz` |            0.077 |              0.920 |
| ECG`0.5–40 Hz`     |            0.815 |              0.971 |
| PPG-IR`0.4–8 Hz`   |            0.658 |              0.994 |

### 3.3 频谱解释

胸廓压力：

- 原始能量主要集中在低频，符合呼吸/体重缓慢变化占主导的现象；
- 呼吸通道在约 0.7 Hz 后迅速衰减；
- 心搏候选通道抑制了低频呼吸，并保留 0.8–8 Hz；
- 高频包络提供另一种机械心搏候选表征。

ECG：

- 低于 0.5 Hz 的基线漂移被明显抑制；
- 40 Hz 以上功率快速衰减；
- 主要 QRS 相关频谱仍位于通带内。

PPG：

- 0.4 Hz 以下的慢漂移受到抑制；
- 8 Hz 以上的高频噪声明显下降；
- 心搏基频及其低阶谐波得到保留。

### 3.4 重要边界

处理后目标频带占比升高是带通滤波的预期数学结果，它可以证明：

- 滤波器实现正确；
- 没有明显数值不稳定；
- 不同通道在频域上实现了预设分工。

它不能证明：

- 心搏候选通道中的主峰一定对应真实心率；
- BCG 能够稳定恢复 ECG；
- 频带内的所有能量都是生理信号。

先前预实验已经表明，BCG 最大频谱峰与 ECG 心率的一致性较差。因此该通道应称为“心搏候选分量”，而不是“已验证心搏信号”。

## 4. ECG 事件与 PPG 教师审计

![ECG和PPG事件审计](experiments/preprocessing_visualization/figure3_event_and_teacher_validation.png)

### 4.1 时域事件

代表性窗口中：

- ECG R 峰在滤波后仍位于明显的 QRS 峰附近；
- PPG 脉搏峰具有较稳定的周期；
- ECG 和 PPG 事件间存在符合生理预期的相位差，不能逐采样强制对齐。

这支持后续将 ECG R 峰作为事件伪标签，并将 PPG 作为延迟容忍的心搏教师。

### 4.2 全数据心率一致性

PPG 两路平均心率相对 ECG：

| 指标               |        数值 |
| ------------------ | ----------: |
| Pearson 相关       |       0.678 |
| MAE                |    4.93 bpm |
| Bland–Altman 偏差 |  −2.88 bpm |
| 95% 一致性下限     | −18.73 bpm |
| 95% 一致性上限     |   12.98 bpm |

中位绝对误差约为 2 bpm，但存在明显异常尾部。Bland–Altman 结果还显示 PPG 心率整体略低估 ECG 心率。

### 4.3 结论

- PPG 足以作为**质量加权的事件教师**；
- PPG 不能在所有窗口中被视为无误差真值；
- 必须使用 IR/RED 相关性和两路心率分歧进行教师门控；
- ECG R 峰仍建议人工检查至少 50 个覆盖不同体位和质量等级的窗口。

## 5. 压力空间结构审计

![压力预处理逐阶段审计](experiments/preprocessing_visualization/figure6_pressure_processing_stages.png)

![压力阵列体位图谱](experiments/preprocessing_visualization/figure4_pressure_posture_atlas.png)

### 5.1 处理方式

- 原始每帧 1056 路数据按参考代码中的硬件接线关系映射为 `77×32`，随后按床垫方向水平翻转；
- 映射不是简单 reshape：2306 个非零映射系数中，2279 个为直接通道复制，27 个为相邻通道的 0.5/0.5 平均；
- 对固定的 6×4 未测区域做线性插值；
- 在原始压力值域内执行 OTSU 阈值分割，并移除面积不大于 10 的四连通小区域；
- 清洗图对前景像素做 z-score，背景保持为 0；
- 体位图谱则对每个窗口 30 帧的非负前景图取平均，并按总负载归一化；
- 每个窗口按总负载归一化，减少不同体重和绝对压力范围影响；
- 再按体位在全部受试者中求平均；
- 白色十字表示平均压力中心。

### 5.2 观察结果

- 原始 `66×16` 采集顺序不具有可直接解释的人体空间结构，硬件映射后出现连续的人体接触形态；
- 固定缺口插值只改变标出的 6×4 局部区域，没有改变其余传感器值；
- 队列代表窗口的中位负载帧中，OTSU 阈值为 1273.0 原始单位，清理后前景占阵列约 9.78%；
- 该窗口 30 帧总负载及激活面积变化连续，没有出现映射造成的离散跳变；
- 五种体位均形成非随机的局部高压区域；
- 坐姿图谱与卧姿图谱差异最明显；
- 仰卧、侧卧和俯卧的压力中心及空间分布存在差异；
- 空间结构与重算后的 0.804 跨受试者体位识别平衡准确率相互支持。

这些结果说明：

- 参考接线映射把 1056 路采集向量还原为 77×32 空间图具有数据层面的合理性；
- 压力图可用于体位、接触状态和质量条件；
- 相对归一化适合学习空间形态。

### 5.3 尚未解决的问题

当前实现已严格继承参考代码中的转置与水平翻转；但尚未获得硬件坐标与人体解剖方向的正式定义，因此：

- 不能把图中的上、下、左、右直接解释为人体解剖方向；
- 不能基于当前方向计算“人体左侧/右侧”临床特征；
- 在正式论文中应标注为 sensor row/column；
- 获得硬件说明后应确认 sensor row/column 与头足、人体左右方向的对应关系，不需要再用数据驱动方式猜测接线重排。

## 6. 全数据质量分布

![全数据质量分布](experiments/preprocessing_visualization/figure5_quality_distributions.png)

图中：

- 淡色散点表示每个 30 秒窗口；
- 粗短横线表示中位数；
- 竖线表示四分位区间；
- 红色虚线为预实验使用的质量门。

### 6.1 质量门通过情况

| 审计项目                   | 通过比例 |
| -------------------------- | -------: |
| ECG 轨到轨比例`<5%`      |    97.3% |
| BCG 尖峰比例`<8%`        |    98.3% |
| PPG IR/RED 相关性`>0.30` |    99.3% |
| PPG 两路心率差`≤12 bpm` |    98.4% |
| 综合信号质量门             |    88.8% |
| PPG 教师综合质量门         |    87.2% |
| 压力阵列有效               |    99.6% |

### 6.2 解释

大部分窗口质量较好，但所有主要模态都存在少量明显异常尾部。综合质量门通过率低于任一单项门，说明异常并不总集中在同一批窗口。

体位分层还显示：

- 坐姿具有较多 ECG 饱和和 BCG 尖峰窗口；
- 左侧卧和俯卧也存在少量明显异常；
- PPG 两路总体高度相关，但个别窗口显著下降；
- 仅用总体平均质量会掩盖这些体位差异。

这支持后续采用：

- 体位条件化质量模型；
- 质量加权训练；
- 高风险窗口拒识；
- 分体位报告性能。

## 7. 对预处理方案的逐项判断

| 处理步骤                  | 可视化证据                                           | 当前判断                     |
| ------------------------- | ---------------------------------------------------- | ---------------------------- |
| 稳健标准化                | 代表与高伪影窗口均未数值发散                         | 合理                         |
| BCG 线性去趋势            | 慢漂移下降，呼吸波动保留                             | 合理                         |
| BCG 呼吸带通              | 时域周期清晰、频谱集中                               | 合理                         |
| BCG 心搏候选滤波          | 频带实现正确，但尚未证明对应真实心率                 | 作为候选通道保留             |
| ECG`0.5–40 Hz`         | R 峰保留、频谱带外衰减                               | 合理                         |
| ECG 自动 R 峰             | 代表窗口合理，仍需人工抽检                           | 可作为伪标签                 |
| ECG 500→100 Hz           | 事件位置在 100 Hz 掩码中保持                         | 适合事件任务                 |
| PPG`0.4–8 Hz`          | 脉搏峰清晰、总体与 ECG 一致                          | 合理                         |
| PPG 教师                  | 存在异常尾部和系统性偏差                             | 必须质量加权                 |
| 压力硬件映射 1056→77×32 | 映射后形成连续人体接触形态；映射与原参考实现误差为 0 | 合理                         |
| 压力缺口插值与前景清理    | 局部插值、OTSU 前景及 30 秒负载轨迹可逐阶段核查      | 合理，阈值需保留为可审计参数 |
| 质量指标与门控            | 能识别全数据异常尾部                                 | 必须保留                     |

## 8. 是否足以证明预处理“可行”

现有可视化足以支持以下表述：

> 预处理能够稳定地分离预设频段，保留 ECG/PPG 主要事件，生成具有体位结构的压力空间表征，并显式识别残余伪影，因此适合作为后续表征学习、质量评估和条件模型的输入。

但不应表述为：

> 预处理已经成功从胸廓压力中提取出可靠心搏，或者已经证明可以重建 ECG。

心搏候选通道的真实性仍必须由事件触发平均、同步核查和跨受试者心搏检测指标验证。



## 11. 下一步建议

在进入模型研究前，建议补完三项验证：

1. 人工核查至少 50 个 ECG R 峰窗口；
2. 使用硬件文档确认压力阵列真实行列方向；
3. 对不同体位做 ECG R 峰触发的 BCG 平均，验证心搏候选分量是否存在稳定机械模板。

完成后，预处理章节就可以形成较完整的“时域—频域—事件—空间—质量”证据链。
